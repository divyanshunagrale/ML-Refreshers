## Run this Yourself

To run the notebooks yourself, the only prerequisites, outside the obvious having access to an environment to the jupyter notebooks, is to have `numpy`, `pandas`, `matplotlib`, `seaborn`, and `scikit-learn` installed.

## Model Metrics
