# 🧪 Mini ML Lab Course (Increasing Difficulty)

| Lab | Dataset & Link | Difficulty | Key Skills Practiced | Time | Why This Lab? |
|-----|----------------|------------|-----------------------|-------|----------------|
| **Lab 1** | **Titanic (Kaggle)** → <https://www.kaggle.com/competitions/titanic> | ⭐ Easy | - Data cleaning & EDA<br>- Missing values<br>- OneHotEncoder<br>- Pipelines + ColumnTransformer<br>- Baseline models (LogReg, RandomForest)<br>- Accuracy / AUC | ~1 day | Perfect warm-up, rebuild ML reflexes, small + clean dataset |
| **Lab 2** | **Heart Disease (UCI)** → <https://archive.ics.uci.edu/dataset/45/heart+disease> | ⭐⭐ Medium | - Imbalanced data handling<br>- Scaling inside pipelines<br>- ROC curves<br>- Confusion matrix<br>- Feature importance / coefficients | 1–2 days | Forces realistic evaluation thinking and handling messy clinical data |
| **Lab 3** | **Option A: Bank Marketing (UCI)** → <https://archive.ics.uci.edu/dataset/222/bank+marketing><br>**Option B: NYC Taxi Trip Duration (Kaggle)** → <https://www.kaggle.com/competitions/nyc-taxi-trip-duration> | ⭐⭐⭐ Medium-High | *If Bank Marketing:*<br>- High-cardinality features<br>- PR curves<br>- Business framing<br><br>*If NYC Taxi:*<br>- Feature engineering (distance, time)<br>- Outlier handling<br>- Log transforms<br>- Time-based validation | ~2 days | Adds real feature engineering, leakage checks, domain insight — needed for recommender systems later |
| **Lab 4** | **MovieLens 100K (GroupLens)** → <https://grouplens.org/datasets/movielens/100k/> | ⭐⭐⭐⭐ High (but manageable) | - User-item interactions<br>- Collaborative filtering (Surprise library)<br>- Train/test by timestamp<br>- RMSE, Recall@k<br>- Top-N recommendation ranking | 2–3 days | Direct precursor to your Anime Recommender project — builds exact mental model you'll need |
